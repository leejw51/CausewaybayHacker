Fonts shipped with the Causewaybay Hacker LÖVE client, and where they come from.

The same faces as frontend/public/fonts (see CREDITS.txt there). LÖVE 11.5
cannot read WOFF or WOFF2, so each was converted back to TrueType/OpenType
with fontTools; the ones only a code pane uses were subset to the range
Iosevka-Code.ttf carries, and the Hangul faces to Latin plus the 2,350
syllables of KS X 1001. A glyph a subset lacks is drawn by the faces behind
it (VT323 or Press Start 2P, then GNU Unifont).

From FruitNation Messenger's font pack, the web's interface faces. Each is
the Google Fonts build cut to one weight (400) from its variable font with
fontTools.varLib.instancer, and its Latin and Latin Extended subsets merged
into one file with fontTools.merge (Nunito Sans has Latin only). Upright only.
GNU Unifont in that list is unifont.otf above, at the front of the stack.

Courier New Bold is not shipped. It is a system face, read at run time from
/System/Library/Fonts/Supplemental/ on macOS, and VT323 stands in for it on
a machine without it.
